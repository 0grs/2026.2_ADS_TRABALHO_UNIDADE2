# Notas da versão

## 1.0.0 — 3 de outubro de 2026

### Funcionalidades

- Contador interativo iniciado em zero, com botões para incrementar e decrementar em duas unidades.
- Alternância entre tema claro e escuro, atualizando as cores de fundo e do texto, o título e a mensagem exibida.
- Indicação acessível do estado do tema no botão de alternância.
- Interface construída em HTML e CSS e conectada à lógica JavaScript do aplicativo.

### Como executar

Abra o arquivo `index.html` em um navegador. A aplicação não exige instalação de dependências.
